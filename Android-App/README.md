
# Aplicación Android - FSleepSync

Este directorio contiene el código fuente de FSleepSync.

La aplicación permite al usuario iniciar sesión y obtener información sobre sus sesiones de sueño mediante Health Connect, utilizando los datos proporcionados por Samsung Health.

Los datos recopilados incluyen las fases del sueño, su duración y la frecuencia cardíaca. Posteriormente, esta información se envía al backend para su almacenamiento y consulta.
